Overview

In this project, we will be taking two images that have a projective transform between them. In this case, we fix the COP and rotate the camera to capture two views. Then, using these two images and manually labelled correspondences, we will solve for the homography/transform to make the correspondences line up, warp the images using the recovered homographies, and then blend them so they make a nice-looking mosaic.

A.2 Recover Homographies

In this part, we construct a system of equations Ah=b to try and solve for the homography h. We can derive the matrix construction through the following:

If we have H (3×3) and multiply by our point p=[xy1], we get

x′=h11x+h12y+h13h31x+h32y+1andy′=h21x+h22y+h23h31x+h32y+1

If you multiply by the denominator and move anything with an h term to the left, we get

h11x+h12y+h13−h31xx′−h32yx′=x′ h21x+h22y+h23−h31xy′−h32yy′=y′

which we can then use as the template for our system below.

A.3 Warp the Images

In order to construct the mosaics, once we obtain the homography, we need a good way to apply it. Here, we can test our algorithms by taking lines that should be axis-aligned with the image but aren’t, and aligning them using a method called rectification. We create a quadrilateral and compute the homography to a predetermined “rectangle” set of corners using the method described above. Now, we can just apply the homography to each pixel to produce our output. Nope, it looks terrible since the destinations rarely land on clean integer pixel indices, so we get an image with holes!

Instead, we can use inverse warping. We take the inverse of H, and for each destination pixel, we apply the inverse homography to calculate a source pixel. This source pixel also will rarely land cleanly on a pixel index, so we can use a method of using the surrounding pixel values to calculate the source pixel value.

Using an inverse warping method with interpolation produces much cleaner results than forward warping. The two interpolation methods tested have tradeoffs. Nearest neighbors works almost 2× as fast but produces aliasing-like artifacts where edges become jaggedy, causing things like text to not look good. Bilinear interpolation solves this problem by blending the surrounding pixels evenly, creating a smoother look.

A.4 Blend the Images into a Mosaic

We have a way to reliably calculate a homography between two images and nicely warp them using a homography. Now, we need to find a way to construct a mosaic of the two. First, we calculate the homography. One of the images is warped using inverse warping + bilinear interpolation. We now need to put the two images on some shared canvas. We pass the corners of one image through H to obtain its warped coordinates and then construct the smallest possible bounding box that contains the unwarped image’s corners and the warped image’s corners. We now have two ways to blend the images.

Feathering: We calculate the distance between each pixel and its nearest pixel with the image data and then normalize with the maximum. This gives us weight of 1 close to the center of the image and smaller and smaller weights as we go to the edges. Then, using these weights at each pixel ij, we calculate

w1,ij⋅im1,ij+w2,ij⋅im2,ijw1,ij+w2,ij

If there’s no overlap at ij, then we get only that pixel fully expressed, and then at places of intersection, it smoothly interpolates between the two images.

This is problematic because small errors in your homography (propagated through human error when labelling correspondences or the two images not having a true projective transform) can cause double ghosting of fine details (as evidenced in the Tahoe images).

Instead, we can use a two-band Laplacian pyramid to blend the high and low frequencies differently.

Two-Band Blending: First, we Gaussian blur the images to obtain the low band, which contains color and broad shapes. For low-band pixels, we use the same feathering technique as above. But for the high band, we pick the pixel which has the higher weight instead of interpolating it. Since fine detail is never averaged, there’s no ghosting, so it’s much harder to see any artifacts.

Conclusion

This project gave me really good intuition for how to take two different viewpoints of a scene and bring them together to create one coherent image. I learned first how to capture two images that are well suited for composition, how to calculate the transform between them, then how to elegantly apply that transform, and finally cleanly blend the warped images to make a nice mosaic.
